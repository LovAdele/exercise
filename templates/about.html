About This Project

This site is the Week 9 hands-on exercise for MIS2001. It is a small Flask web application that is built, deployed and made reachable over the local network.

The app serves a single homepage from port 8000 and is bound to all network interfaces, so teammates on the same network can open it with this machine's IP address. The project is version-controlled with Git and pushed to GitHub for the group collaboration exercise.
