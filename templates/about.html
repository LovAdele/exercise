About This Project

This page is part of the MIS2001 Week 9 hands-on exercise. The exercise shows how a small web app is built with Flask, run on a local server and shared over the campus network.

The app serves its homepage on port 8000 and listens on all network interfaces, so classmates on the same network can open it with this machine's IP address. The source code is managed with Git and pushed to GitHub, where each team member adds a page on a separate branch before it is reviewed and merged.
